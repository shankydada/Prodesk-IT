#  Cash Flow Tracker

A responsive **Salary & Expense Tracker** built using **Vanilla JavaScript**, **Tailwind CSS**, **Chart.js**, and **jsPDF**. This project was developed as part of Sprint 2 to demonstrate DOM manipulation, state management, LocalStorage persistence, and client-side data visualization.

---

## Live Features

###  Salary Management

* Set or update the total salary.
* Automatically recalculates remaining balance.

### Expense Tracking

* Add expenses with a name and amount.
* Dynamically renders expenses without page refresh.
* Delete individual expenses.

### Financial Overview

* Displays:

  * Total Salary
  * Total Expenses
  * Remaining Balance

### LocalStorage Persistence

* Saves salary and expenses locally.
* Automatically restores data after page reload.

### Expense Visualization

* Interactive Pie Chart using Chart.js.
* Updates automatically whenever data changes.

### Currency Conversion

* Toggle between USD and INR.
* Uses the Frankfurter Exchange Rate API.

### PDF Report

* Generate and download a PDF summary of salary, expenses, and remaining balance using jsPDF.

### Threshold Alert

* Highlights the remaining balance in red when it falls below 10% of the total salary.

```bash

```

2. Open the project folder

```bash

```

3. Launch `index.html` in your browser or use a local development server (such as VS Code Live Server).
